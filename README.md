# ЮК «АКТИВ» — сайт aktiv-alb.com

Новий сайт юридичної компанії «АКТИВ» замість старого WordPress.
Цей README — для гілки **`redesign-client`** (нова редакція за макетом клієнта).
Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + Sanity CMS, хостинг — Netlify.
Мови: українська (`/`) та англійська (`/en`).

Дизайн — у Figma: <https://www.figma.com/design/uEZLgfCcNnEAEcnjHlwDOO>
(сторінки «A+ · …» — актуальна редакція).

---

## Гілки

| Гілка | Що в ній | Куди деплоїться |
|---|---|---|
| `main` | сайт, що зараз у продакшені | основний домен |
| `redesign-client` | нова редакція за макетом клієнта («A+»): головна, практики, напрям, послуга, про компанію, команда, карʼєра, новини, стаття, політика | `redesign-client--radiant-fenglisu-4b499d.netlify.app` |
| `redesign-3d` | ця ж редакція + живі 3D-сцени (three.js), окрема папка й окремий README | вмикається окремо в Netlify, див. «Деплой» |

Злиття в `main` = викладка на бойовий сайт. Робіть це лише після перегляду превʼю.

## Швидкий старт

```bash
npm install
cp .env.example .env.local   # можна лишити порожнім
npm run dev                  # http://localhost:3000
```

Сайт запускається **без жодної змінної оточення**: поки Sanity не підключено,
весь контент береться зі статики в `lib/`. Кожен блок сам переходить на Sanity,
щойно там зʼявляються опубліковані дані.

Перед комітом:

```bash
npm run check    # typecheck + перевірка схем Sanity + перевірка GROQ-запитів
npm run build    # продакшен-збірка
```

## Змінні оточення

| Змінна | Де потрібна | Навіщо |
|---|---|---|
| `NEXT_PUBLIC_SANITY_PROJECT_ID` | сайт | id проєкту Sanity (зараз `q2tr45a7`) |
| `NEXT_PUBLIC_SANITY_DATASET` | сайт | `production` |
| `NEXT_PUBLIC_SANITY_API_VERSION` | сайт | необовʼязково, за замовчуванням `2026-01-01` |
| `SANITY_STUDIO_PROJECT_ID`, `SANITY_STUDIO_DATASET` | студія | ті самі значення — студія читає лише змінні з цим префіксом |
| `SANITY_API_READ_TOKEN` | сайт | лише якщо датасет закритий |
| `SANITY_API_WRITE_TOKEN` | локально | тільки для `npm run seed` і службових скриптів. **Не додавати в Netlify** |
| `SANITY_REVALIDATE_SECRET` | сайт | секрет вебхука, що скидає кеш після публікації |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | сайт | сповіщення про нові заявки й резюме |
| `NEXT_PUBLIC_IMAGE_PROXY` | сайт | необовʼязково |

Після зміни `.env.local` перезапустіть `npm run dev` — Next читає файл лише під час старту.

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | локальний сервер (перед стартом перевіряє GROQ-запити) |

| `npm run studio` | Sanity Studio локально |

## Звідки береться контент

| Що | Звідки |
|---|---|
| Практики й послуги (сторінки напряму та послуги, текст, «Що входить», FAQ) | Sanity: `practiceCategory`, `practice` |
| 8 напрямів на головній і в мега-меню | `lib/v2/practices.ts` (поки в Sanity 4 категорії, а не 8) |
| Тексти нової редакції (заголовки, «Як ми працюємо», ціннісні блоки) | `lib/v2/content.ts` |
| Команда | Sanity: `teamMember`, `teamPage` |
| «Напрям веде» / «Справу веде» | привʼязка юриста до практики в Sanity (поле в картці юриста або в практиці). Без привʼязки блок не показується |
| Новини | Sanity: `post`. Поки статей немає, сторінка статті не генерується |
| Вакансії | Sanity: `vacancy`, `careerPage` |
| Контакти, налаштування, логотипи клієнтів | Sanity: `siteSettings` |
| Політика конфіденційності | код: `app/[lang]/privacy/page.tsx` |

Сайт читає лише **опубліковані** документи. Чернетки в студії на сайті не видно.

Логотипи клієнтів показуються лише з галочкою «Дозвіл» у Sanity: чужа торгова марка
без згоди власника — претензія, а не доказ. Без жодного логотипа блок «Нам довіряють»
у продакшені не виводиться.

## Дизайн-правила

Токени — лише в `@theme` у `app/globals.css`. Основне:

- **Кольори:** чорнило `#0b0710`, папір `#f7f3f1`, малиновий логотипа `#fa2163`
  (графіка, логотип), `#e01055` — заливка кнопок (контраст 4.8:1 з білим),
  `#d81b52` — дрібний текст на світлому, `#ff6b92` — на темному.
- **Шрифти:** Montserrat ExtraBold — лише великий заголовок першого екрана;
  Playfair Display — заголовки секцій і картки; Manrope — текст і інтерфейс.
  Курсиву на сайті немає (`em, i { font-style: normal }`).
- **Малиновий** — кнопки дії, логотип, другий рядок заголовка першого екрана.
  Заголовки секцій — одним кольором, без виділення окремого слова.
- **Без:** капслоку й моноширинного шрифту в підписах, нумерації 01–08 там, де немає
  послідовності (номери лишаються лише в кроках «Як ми працюємо» та етапах),
  стрілок усередині тексту кнопок, рожевого світіння під кнопками,
  декоративних надзаголовків над секціями.
- **Доступність:** цілі нажимання від 44 px, видимий фокус, `prefers-reduced-motion`
  поважається скрізь, рядок тексту до ~75 символів.
- Банер cookie: «Лише необхідні» й «Прийняти всі» однакового розміру.

## Заявки

Форма заявки (`app/actions/lead.ts`) і форма резюме перевіряються на сервері й
надсилаються в Telegram, якщо задано `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.

> **Важливо.** На Netlify заявки ніде не зберігаються: відвідувач бачить «Дякуємо»,
> але без Telegram-змінних звернення **губиться**. До запуску на бойовому домені
> задайте обидві змінні й надішліть тестову заявку.

`/admin` — проста CRM (заявки, резюме, статуси, нотатки). Поки це демо в памʼяті
без входу, яке зберігає заявки лише локально: перед продакшеном потрібні база й авторизація.

## Кеш і чому правка в Sanity не видна одразу

| Шар | Тримає |
|---|---|
| CDN Sanity | ~60 с |
| Кеш `fetch` у Next | 300 с |
| Пререндер сторінки | до перезбірки або ревалідації |

У `npm run dev` кеш вимкнено — правку видно після оновлення сторінки.
У продакшені кеш скидає вебхук:

1. Задати `SANITY_REVALIDATE_SECRET` у Netlify.
2. sanity.io/manage → API → Webhooks → Create:
   ```
   URL          https://ДОМЕН/api/revalidate
   Dataset      production
   Trigger on   Create, Update, Delete
   Filter       _type in ["practice","practiceCategory","post","teamMember","siteSettings","vacancy","careerPage","homePage","aboutPage","teamPage"]
   Method       POST
   Header       x-revalidate-secret: <той самий секрет>
   ```
3. GET на `/api/revalidate` показує, чи налаштовано маршрут (без секрету нічого не скидає).

## Діагностика

- **`/sanity-check`** у браузері — чи бачить сайт Sanity, і звідки зараз береться контент.
- **`npm run sanity:doctor`** — що опубліковано в датасеті по кожному типу, де лише чернетки,
  і з якого джерела бере дані кожен блок.

Найчастіші причини «не підтягується»: документ не опубліковано; не перезапущено `dev`
після зміни `.env.local`; id записано лише в `NEXT_PUBLIC_*`, а студії потрібен ще `SANITY_STUDIO_*`.

## Деплой (Netlify)

- Проєкт `radiant-fenglisu-4b499d`, репозиторій `ez-dev-001/Aktiv`.
- Збірка: `npm ci && npm run build`, публікація `.next`, плагін `@netlify/plugin-nextjs`.
- `main` → продакшен. Деплой гілок увімкнено для `redesign-client`;
  щоб отримати превʼю `redesign-3d`, додайте її в Project configuration →
  Build & deploy → Branches and deploy contexts → Branch deploys.
- Превʼю гілки збирається лише після нового пушу в неї.
- Змінні оточення задаються в Netlify, `.env.local` у репозиторій не потрапляє.

## Що ще потрібно від клієнта

1. Фото юристів (зараз монограми) — завантажити в картки команди в Sanity.
2. Привʼязати юристів до практик у Sanity — тоді на сторінках напрямів і послуг
   зʼявиться «Напрям веде…».
3. Логотипи клієнтів із письмовим дозволом.
4. Перші статті в розділі «Новини».
5. Токен Telegram-бота і `chat_id` команди для сповіщень про заявки.
6. Опублікувати в Sanity чернетку картки «Альона Білянівська».
